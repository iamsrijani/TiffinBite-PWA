# 🍱 TiffinBite — Daily Tiffin Subscription & Delivery PWA

> A full-stack Progressive Web Application for daily home-style meal subscription and delivery, built for Indian users.



---

## 📱 What is TiffinBite?

TiffinBite solves the daily problem of affordable, healthy home-cooked food for students and working professionals in Indian cities. Users subscribe to weekly or monthly tiffin plans and get meals delivered automatically — no re-ordering every day.

## 📲 PWA Features

TiffinBite is built as a Progressive Web App — it works like a native mobile app without needing the Play Store or App Store.

### 1. 📄 Web Manifest
**File:** `client/public/manifest.webmanifest`

The web manifest is a JSON file that tells the browser how the app should behave when installed. It defines the app name, icons, theme color, and display mode.

```json
{
  "name": "DailyBite - Daily Meal Delivery",
  "short_name": "DailyBite",
  "display": "standalone",
  "theme_color": "#ff6b35",
  "start_url": "/"
}
```

**Why it matters:** This is what makes the app installable on any Android or iOS device directly from the browser — no app store needed.

---

### 2. ⚙️ Service Worker
**Files:** `client/public/sw.js`, auto-generated by `vite-plugin-pwa`

A service worker is a background script that runs separately from the main app. It intercepts all network requests and can cache responses for offline use.

```javascript
self.addEventListener('fetch', (event) => {
  event.respondWith(
    fetch(event.request).catch(() => {
      return caches.match('/offline.html');
    })
  );
});
```

**Why it matters:** Enables offline support, faster loading, and push notifications. The app loads from cache even on slow 2G connections.

---

### 3. 🔔 Push Notifications (Firebase Cloud Messaging)
**Files:** `client/src/firebase.js`, `client/public/firebase-messaging-sw.js`

Integrated Firebase Cloud Messaging (FCM) to send real-time delivery alerts to users even when the app is closed.

```javascript
const token = await getToken(messaging, { vapidKey: VAPID_KEY });
// Token is saved to server
// When order is delivered, server sends push notification to this token
```

**How it works:**
1. User opens app → asked for notification permission
2. Firebase generates a unique device token
3. Token is saved to our backend
4. When delivery partner marks order delivered → server triggers FCM
5. Notification appears on user's phone even if app is closed

**Why it matters:** Core PWA feature using Web Push API — same technology used by Swiggy and Zomato for delivery alerts.

---

### 4. 📲 Install Banner
**File:** `client/src/components/InstallBanner.jsx`

A custom install prompt that appears at the bottom of the screen, encouraging users to install the app on their home screen.

```javascript
window.addEventListener('beforeinstallprompt', (e) => {
  e.preventDefault();
  setDeferredPrompt(e); // Save the event
  setShowBanner(true);  // Show custom banner
});

const handleInstall = async () => {
  deferredPrompt.prompt(); // Trigger install
};
```

**Why it matters:** Uses the `beforeinstallprompt` PWA-specific browser event to show a branded install experience instead of the default browser prompt.

---

### 5. 📴 Offline Page
**Files:** `client/public/offline.html`, `client/public/sw.js`

Instead of showing a blank error page when the user has no internet, we serve a friendly offline page cached by the service worker.

```javascript
// Service worker caches offline.html during install
caches.open('dailybite-v1').then((cache) => {
  cache.addAll(['/offline.html', '/icons/icon-192x192.png']);
});

// Serves it when network fails
fetch(event.request).catch(() => caches.match('/offline.html'));
```

**Why it matters:** Part of the "reliable" pillar of PWA — the app always shows something meaningful, never a blank screen.

---

### 6. 🔴 App Badging
**File:** `client/src/hooks/useAppBadge.js`

Shows a notification count badge on the installed app icon — exactly like WhatsApp shows unread message count.

```javascript
const useAppBadge = (count) => {
  useEffect(() => {
    if ('setAppBadge' in navigator) {
      count > 0 
        ? navigator.setAppBadge(count) 
        : navigator.clearAppBadge();
    }
  }, [count]);
};
```

**Why it matters:** Uses the `navigator.setAppBadge` Web API which is only available for installed PWAs — not regular websites. Shows pending orders on the app icon.

---

### 7. 🍱 Splash Screen
**File:** `client/src/App.jsx`

A branded loading screen that appears when the app opens — just like native apps.

```javascript
const [showSplash, setShowSplash] = useState(true);
useEffect(() => {
  setTimeout(() => setShowSplash(false), 2000);
}, []);
```

**Why it matters:** Improves perceived performance — users see the branded screen immediately while the app loads in the background.

---

### 8. 📶 Network Status Banner
**File:** `client/src/components/NetworkStatus.jsx`

Real-time network detection that shows a red banner when offline and green when back online.

```javascript
window.addEventListener('offline', () => {
  setIsOnline(false);
  setShowBanner(true);
});
window.addEventListener('online', () => {
  setIsOnline(true);
  setShowBanner(true);
  setTimeout(() => setShowBanner(false), 3000);
});
```

**Why it matters:** Combined with the offline page and service worker, gives users a complete and seamless offline experience.

---

### 9. ↕️ Pull to Refresh
**File:** `client/src/hooks/usePullToRefresh.js`

Standard mobile app gesture — pull down from top to refresh data.

```javascript
const handleTouchEnd = async (e) => {
  const endY = e.changedTouches[0].clientY;
  if (endY - startY > 100 && window.scrollY === 0) {
    await onRefresh(); // Refresh data
  }
};
```

**Why it matters:** Makes the app feel completely native on mobile phones — a gesture users expect in any mobile app.

## 🗃️ Caching Strategies (Workbox)
**File:** `client/vite.config.js` → `workbox.runtimeCaching`

| Strategy | Used For | How it works |
|---|---|---|
| NetworkFirst | API calls (/api/*) | Tries network first, uses cache if offline |
| CacheFirst | Images (.png, .jpg, .svg) | Serves from cache instantly, reduces network usage |
| StaleWhileRevalidate | JS/CSS static files | Shows cached version immediately, updates cache in background |
| NetworkOnly | Socket.io real-time | Never caches — always fetches live data |
| CacheOnly | Offline page | Only serves from cache, no network request needed |
